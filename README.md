# 동인도회사 웹판

보드게임 동인도회사(East India Companies, 2023)를 친구끼리 온라인으로 두려고 옮긴 웹판이다.
4인 규칙만 들어 있다. 2·3인 규칙은 아직 없다.
원작 그림은 쓰지 않는다. 판·말·큐브·배는 모두 직접 그린 것이다.
지도 해안선은 Natural Earth 1:50m(공공 영역)을 `tools/geo.mjs`로 잘라 `src/geo.js`에 넣었다.

## 조작

- 요원·배는 끌어다 놓는다. 눌러서 고른 뒤 놓을 칸을 눌러도 된다.
- 빈 테이블을 끌면 화면이 움직이고, 휠이나 두 손가락으로 확대한다.
- 차례가 오면 할 곳으로 시점이 옮겨 간다. 왼쪽 위 「자동 시점」으로 끌 수 있다.

## 하는 법

1. 깃허브 페이지 주소를 연다.
2. 한 사람이 닉네임을 적고 「새 방 만들기」를 누른다. 이 사람이 방장이다.
3. 「링크 복사」로 받은 주소를 친구에게 보낸다. 친구는 그 주소를 열거나 방 코드 4글자를 입력한다.
4. 네 자리가 다 차면 「게임 시작」. 한 사람이 여러 자리에 앉아도 된다.

- 계정이나 가입은 필요 없다.
- 방장 브라우저가 규칙을 판정한다. 방장 창을 닫으면 게임이 멈춘다.
  방장이 같은 브라우저로 다시 열면 「내가 만든 방 이어서 하기」로 그대로 이어진다.
- 손님에게는 남이 뒤집어 둔 배와 남이 미리 본 시장 카드를 보내지 않는다.
- 새로고침하거나 잠시 끊겨도 같은 자리로 돌아온다(브라우저에 저장된 표식으로 알아본다).

## 연결 방식과 한계

브라우저끼리 직접 잇는다(WebRTC). 서로를 찾는 데만 PeerJS의 무료 공개 중계 서버(0.peerjs.com)를 쓴다.
게임 내용은 그 서버를 지나지 않는다.

- 회사·학교 망이나 일부 휴대폰 데이터망에서는 직접 연결이 막힐 수 있다.
  안 되면 와이파이로 바꿔 본다. 그래도 안 되면 TURN 서버를 붙여야 한다.
- 공개 중계 서버가 쉬면 방을 만들 수 없다. 그럴 땐 잠시 뒤 다시 한다.

## 구조

| 경로 | 내용 |
| --- | --- |
| `index.html` | 깃허브 페이지가 여는 게임(빌드 결과) |
| `peerjs.min.js` | PeerJS 1.5.4 (MIT) |
| `data/eic-data.json` | 배·주가 트랙·시장판·시장 카드 수치. 실물 화면과 대조함(2026-11-14) |
| `src/engine.js` | 규칙 엔진. `(상태, 행동) → 새 상태`, 같은 씨앗이면 같은 판 |
| `src/map_antique.js` | 인도양 지도: 시대별 옛 지도 양식(물결선·손채색·수심·지도첩 색), 한 번 그림으로 구워 가볍게 |
| `src/ui_table.js` | 위에서 내려다본 테이블 화면: 판·말·큐브·배를 직접 그림, 끌어다 놓기, 이동·확대, 말 움직임 |
| `src/net_p2p.js` | 깃허브 판 온라인 방(방장 판정, 숨김 정보 가리기, 재접속) |
| `src/net_db.js` | claude.ai 아티팩트 판 온라인 방(공유 저장소 사용) |
| `src/template.html` | 화면 틀과 스타일 |
| `src/build.py` | `index.html`과 `dist/artifact.html`을 만든다 |
| `tests/` | 룰북 예시, 무작위 판 수천 회, 방장·손님 두 브라우저 흉내 |

## 고칠 때

```sh
python3 src/build.py          # index.html 다시 만들기
node tests/examples.mjs       # 룰북 예시와 특수 규칙
node tests/fuzz.mjs 1000      # 무작위 1000판: 멈춤·불변식 위반 찾기
node tests/p2ptest.cjs        # 방장·손님 한 판, 숨김 정보 새는지, 재접속
```

## 룰북에서 애매해 임시로 정한 규칙

- 판매는 빠른 배(속도 4)부터, 같은 속도는 주도권 순.
- 판매 마커는 10 단위로 내림(43GP → 40+).
- 같은 캐릭터 칸에 남의 요원이 있으면 한 명당 1GP를 주고 놓을 수 있다. 내 요원이 있으면 못 놓는다.
- 중앙에서 다른 칸으로 옮기는 것도 배치 차례 하나를 쓴다.
- 동점은 자기 회사 주가 → 현금 → 주도권 순.
- 주가는 트랙 양 끝에서 멈춘다.
- 꼭 내야 할 돈이 모자라면 먼저 주식을 팔게 하고, 그래도 모자라면 부채로 남긴다.
  부채는 기간 끝마다 자동으로 갚고, 남은 부채는 최종 점수에서 뺀다.

## 확장: 시대의 사건 (직접 만든 규칙)
- 로비에서 켜고 끈다(기본 켬). 새 게임부터 적용되고, 온라인 방은 만들 때의 설정을 따른다.
- 기간마다 A 단계 처음에 그 시대 사건 카드 6장 가운데 1장을 뽑아 그 기간 내내 적용한다.
- 효과 종류: 인도 공급, 유럽 수요, 지역 항해비, 지역 적재 값, 유럽 판매 값, 배 값.
- 사건 때문에 어디로도 항해할 돈이 없으면 가장 싼 지역으로 가고 모자란 돈은 부채가 된다.
- 끄면 기본판과 완전히 같은 진행이다(같은 씨앗이면 같은 결과).
